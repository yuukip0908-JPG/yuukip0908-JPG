# 笹岡 裕貴（Yuki Sasaoka）

AI エージェントで作るエンジニアを目指しています。
2025年秋に生成 AI でのアプリ制作を始め、いまは Claude Code と Codex で、テストと自動チェック付きのシステムを作っています。

大事にしているのは、**AI の「できました」をそのまま信じないこと**です。合否を決める役は、テストや実測の数字を出す仕組みの側に置きます。

## 代表作

| 作品 | 何をするものか | 見どころ |
|---|---|---|
| [h3-studio](https://github.com/yuukip0908-JPG/h3-studio) | 動画生成 AI をクラウド GPU で再現し、Mac の画面から費用を見張りながら使うスタジオ | 「数倍遅い」とされていた設定を実測して1.07倍だったと書き直した記録、GPU の止め忘れ対策、戻れる版に付けた印 |
| [ai-video-editing-agent](https://github.com/yuukip0908-JPG/ai-video-editing-agent) | 撮った素材からショート動画を仕上げる、役割を分けた AI 担当の仕組み | AI は案を出し、字幕や尺などの条件はスクリプトの数字で確かめ、映像の良し悪しは人が判断する |
| [sales-meeting-workspace](https://github.com/yuukip0908-JPG/sales-meeting-workspace) | 商談要約を1回貼るだけで、議事録・報告書・お礼メール・ToDo を作る Web アプリ | 人が「確定」したデータからすべての書類を作るので、書類どうしが食い違わない |

このほか、Next.js と Supabase の Web アプリや、テスト2,687個を毎晩動かす画像生成スタジオは非公開で開発しています。面談では画面を見せながら説明できます。

## 作り方

課題とやらないことを決める → 設計を書く → AI に実装を頼む → **テストと実測で確かめる** → 失敗の原因を記録して、次の関所にする

## よく使う技術
